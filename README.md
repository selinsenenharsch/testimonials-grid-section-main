# Testimonials Grid Section

My solution to the [Frontend Mentor Testimonials Grid Section challenge](https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7).

I built this project to practice HTML and CSS, especially CSS Grid. I worked through the layout one step at a time and used the desktop and mobile designs as references.

## What I built

- Five testimonial cards with author photos and review text
- A desktop layout made with CSS Grid
- A single-column layout for smaller screens
- Different card colors and spacing to match the design

## What I learned

- `display: grid` turns a parent element into a grid container for its children.
- `grid-template-columns` sets up the grid's columns, and `1fr` gives a column an equal share of the available space.
- `gap` adds consistent space between grid items.
- `grid-column: span 2` lets a card take up two columns.
- A media query can change the layout on smaller screens. I changed the grid to one column and reset the desktop card placements so the testimonials stack in order.
- Flexbox is useful for a smaller one-dimensional layout, like placing each author's photo beside their name.

## Built with

- Semantic HTML
- CSS Grid
- CSS Flexbox
- CSS media queries

## Running the project

Open `index.html` in a web browser. Resize the browser to compare the desktop and mobile layouts.
